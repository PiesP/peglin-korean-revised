# 번역 CSV 형식

외부 기여자가 수정하는 번역은 범주별 `translation/terms/<slug>.csv` 파일에
저장됩니다. 각 파일은 UTF-8 CSV이며 첫 줄의 열 순서는 다음과 같습니다.

```csv
Term,Translation,Status,ReviewedBuildId,Comment
```

## 열 설명

| 열 | 내용 |
| --- | --- |
| `Term` | 게임 문구를 식별하는 고유 키입니다. 기존 값을 변경하지 않습니다. |
| `Translation` | 게임에 표시할 한국어 번역입니다. |
| `Status` | 검토 상태입니다. 외부 기여는 항상 `draft`로 작성합니다. |
| `ReviewedBuildId` | 실제 게임에서 검토한 빌드 ID입니다. 외부 기여자는 비워 둡니다. |
| `Comment` | 문맥, 번역 의도나 검토할 사항을 적는 칸입니다. |

값에 쉼표, 줄바꿈 또는 큰따옴표가 들어가면 표준 CSV 방식으로 값을 큰따옴표로
감싸고, 값 안의 큰따옴표는 두 번 써야 합니다. 기존 줄바꿈과 자리표시자, 마크업은
번역에서도 그대로 보존합니다.

예를 들어 `{0}`, `%s`, `<b>...</b>`, `[tag]` 같은 표시는 게임이 실행 중에
값이나 서식을 넣는 데 사용합니다. 위치를 옮길 필요가 있더라도 철자와 개수,
여는 태그와 닫는 태그의 짝은 바꾸지 마세요.

## 소스 잠금 파일

`translation/source-lock.json`은 각 `Term`을 관리자가 확인한 게임 원문과
연결하는 메타데이터입니다. 원문의 해시와 보호해야 할 토큰 등 패치 검증에 필요한
정보를 담으며, 원문 전체를 외부 기여용 CSV에 복제하지 않습니다.

해시와 토큰 목록은 관리자가 게임 자료를 확인하여 갱신합니다. 일반적인 번역
기여에서는 `translation/source-lock.json`을 수정하지 않고 해당 CSV 행만
수정합니다. 원문이 바뀐 것으로 보이면 PR에서 잠금 파일을 직접 고치는 대신
게임 버전과 발견한 상황을 알려 주세요.
